# 四兄弟麻雀 ルールまとめ

粗品（霜降り明星）のYouTubeチャンネル「粗品 Official Channel」で行われている、
「ギャンブル四兄弟」（粗品・前田龍二・シモタ・大東翔生）による麻雀企画のルールまとめです。

> **注意**
> チャンネルから公式のルール表は公開されていません。
> 本ファイルは、動画内での描写・出演者の発言・ファンによるまとめ（note等）をもとに整理した**非公式のまとめ**です。
> 収録回によって細部が変わっている可能性があります。

---

## 1. 基本形式

- **三人打ち（サンマ）** を基本とし、メンバーは4人いるため **「四人回し」**（1人が抜け番になり交代で打つ）で進行する。抜け番の人は食事・休憩をしたり、横から観戦したりする
- ベースは **関西式三人打ち（関西サンマ）** に近いルール
- 東南戦（東場・南場）で回す
- 金銭は賭けておらず、勝敗の可視化のために動画内独自通貨 **「ソシー」** を用いる

## 2. 使用牌

- 萬子の2〜8を抜いた、三人打ち標準の牌構成
- **赤ドラ：5が各色すべて赤**（5筒×4枚・5索×4枚の計8枚、関西サンマ流の「オール赤5」）
- **北は「ガリ」（抜きドラ）** として扱う
  - 北をツモったら手牌から抜いて場に晒し、嶺上牌を補充する
  - 和了時、抜いた枚数分がドラとして加算される
  - 動画では前田が北を抜く際に「PayPay♪」と口ずさむのが名物

## 3. 進行に関するルール

- チーは不可（三人打ちのためポン・カンのみ）
- **喰いタン・後付けなし**（いわゆる「ナシナシ」寄りの先付けルール）
- 喰い替えなし
- 東場・南場ともに **親はテンパイで連荘**
- 積み棒（本場）あり
- リーチ棒は供託扱い。ダブロン等が発生した場合は上家取り
- **フリテンリーチあり**（ただしツモ和了のみ可）

## 4. 点数・ドラに関するルール

- 符計算は行わない（翻数ベースの簡易計算）
- **ドラめくり：開門位置を決めるサイコロの出目で表ドラの枚数が変動する**
  - 通常の出目 → 表ドラ **1枚**
  - ゾロ目 → 表ドラ **2枚**
  - **6のゾロ目（6・6）のみ → 表ドラ3枚**
  - ※リーチ時の裏ドラも、めくれている表ドラと同じ枚数分乗る
- オール赤5・ガリ・複数ドラめくりが重なるため打点がインフレしやすく、満貫以上の和了が頻発するのが特徴

## 5. 精算・祝儀に関するルール

- ウマ：**+10 / +5 / -5 / -10**
- 役満祝儀：**全員から1000（単位はソシー換算）**、先着1名のみ・数え役満は対象外。責任払い（パオ）あり
- オーラスで親が3万点を超えてトップの場合はそこで終了（和了やめ・テンパイやめ相当）
- チョンボは供託扱い（暫定運用）

## 6. 雰囲気・名物要素（ルール外）

- 毎回恒例の **開幕自己紹介**（つかみ）が名物で、切り抜きまとめが作られるほど人気
- 実力評価は「龍さん（前田）と翔生くん（大東）が強い、粗品は中間、下ちゃん（シモタ）はド下手」というのが定説
- 特別企画として **24時間麻雀** が複数回開催されており、BSよしもとで6時間SPとして放送されたこともある

# スペック3: 点数計算・ドラ・ソシー精算

対象: 和了点の算出と、半荘終了後のソシー精算。

## 3.1 点数計算(符計算なし・翻数ベース)

- **符計算は行わない**。翻数から標準テーブルで点数を決定する。
- 点数区分(標準準拠):

| 翻 | 区分 | 子(ロン/ツモ合計) | 親(ロン/ツモ合計) |
|---|---|---|---|
| 〜4 | 通常 | 翻数に応じた標準点 | 同左 |
| 5 | 満貫 | 8,000 | 12,000 |
| 6–7 | 跳満 | 12,000 | 18,000 |
| 8–10 | 倍満 | 16,000 | 24,000 |
| 11–12 | 三倍満 | 24,000 | 36,000 |
| 13+ | 役満 | 32,000 | 48,000 |

### ツモ和了時の支払い配分(ツモ損なし・北家折半方式)(Q12)

サンマは**北家(4人目)が不在**のため、不在の北家が負担するはずの分を**親と子で折半**して負担する。これにより**ツモ和了者はロンと同額を受け取る**(いわゆる「ツモ損なし」・西日本サンマ主流)。親被りは通常どおり親が子の2倍を負担する。

**標準区分の支払い対応表(単位: 点):**

| 区分 | 子ツモ(親払い / 子払い) | 親ツモ(子各払い) |
|---|---|---|
| 満貫 | 5,000 / 3,000 | 6,000 |
| 跳満 | 7,500 / 4,500 | 9,000 |
| 倍満 | 10,000 / 6,000 | 12,000 |
| 三倍満 | 15,000 / 9,000 | 18,000 |
| 役満 | 20,000 / 12,000 | 24,000 |

**受取合計(いずれもロンと同額になる = ツモ損なし):**

- **子ツモ**: 支払者は**親1人+子1人**(サンマの着席は東/南/西で、子和了時の払い手は親と残り1子)。受取合計 = 親払い + 子払い(例: 満貫 5,000 + 3,000 = **8,000** = 子ロンと同額)。
- **親ツモ**: 支払者は**子2人**(南・西)。受取合計 = 子各払い × 2(例: 満貫 6,000×2 = **12,000** = 親ロンと同額)。
- **4翻以下も同アルゴリズム**で算出する(親被り=親が子の2倍)。

**擬似アルゴリズム(北家折半・ツモ損なし)**

`u` を標準の基本支払単位(4人打ち相当の1子分。満貫 `u=2000`、親満貫 `u=4000` … 標準テーブル準拠)とする。**不在の北家席が本来払う `1u` を、実在の払い手へ均等に上乗せ**する。

```
tsumoSplit(u_child, u_dealer, winnerIsDealer):
  # u_child = 子和了時の1子分, u_dealer = 親和了時の1子分(=標準4人打ちの1子払い)
  if winnerIsDealer:
    # 親ツモ: 4人打ちなら子3人が各 u_dealer。不在北家の u_dealer を
    # 実在の子2人へ均等分配(+u_dealer/2 ずつ) → 子各 1.5*u_dealer
    return { eachChild: 1.5 * u_dealer }        # 満貫 u_dealer=4000 → 6000
  else:
    # 子ツモ: 4人打ちなら 親 2u_child + 子2人 各 u_child。
    # 不在北家(子)の u_child を 実在の払い手(親+子)へ均等分配(+u_child/2 ずつ)
    fromDealer = 2 * u_child + u_child / 2       # 満貫 u_child=2000 → 5000
    fromChild  = 1 * u_child + u_child / 2       #                  → 3000
    return { fromDealer, fromChild }
```

> 上表を SSOT とし、下位翻(4翻以下)も同じ北家折半ロジックを適用する。ロン時は北家折半を行わず標準テーブル(3.1 冒頭表)どおり(子8,000 / 親12,000 等)。端数は百点単位で切り上げる慣行に従う。

## 3.2 翻に加算されるドラ(打点インフレ要因)

和了時、以下をすべて翻として加算する:

| ドラ種 | 加算 |
|---|---|
| 表ドラ | その局の枚数(1〜3枚、2.2参照)分めくり、該当牌1枚1翻 |
| 裏ドラ | リーチ和了時のみ、表と同枚数分 |
| 赤5(オール赤5) | 手牌中の赤5筒・赤5索 1枚1翻 |
| ガリ(北抜き) | 抜いた北 1枚1翻 |

表ドラ枚数(サイコロ出目→1〜3枚)と、王牌内の表示牌の選定位置・裏ドラの開示条件は→ スペック2 2.2(重複記載しない)。

### 次牌写像(ドラ表示牌 → 実ドラ)

表ドラ・裏ドラは、**表示牌の「次の牌」**が実ドラになる(標準の次牌ルール)。翻集計は実ドラの**牌種(種別・数)で照合**する。写像は以下:

| 表示牌の種別 | 次牌(実ドラ)の巡回 |
|---|---|
| 筒子 | 1→2→…→9→1(9 の次は 1) |
| 索子 | 1→2→…→9→1(9 の次は 1) |
| 萬子 | **一萬↔九萬**(一萬→九萬、九萬→一萬)※本変種固有(下記) |
| 風牌 | 東→南→西→北→東 |
| 三元牌 | 白→發→中→白 |

**本変種固有ルール(萬子 一萬↔九萬)**

- 本変種の萬子は **一萬・九萬のみ**で、2〜8萬が存在しない(1.2)。そのため通常の「次の数牌」(例: 一萬→二萬)が定義できず、**一萬と九萬を相互の次牌**とする(一萬→九萬、九萬→一萬)。
- これは標準関西サンマ慣行に基づく**確定仕様**であり、実装(#78 `src/domain/dora/indicator.ts`)と一致する。**異論があれば実装(#78)とともに見直す**余地を残すが、本 spec では本案を確定とする。

> 実ドラの赤フラグ(`isRed`)は牌集合の規約(5筒・5索は常に赤、1.2 / 4.4)に従って算出する。ドラの照合は牌種で行い、赤5そのものの1翻(上表)とは独立に加算される。実装は `src/domain/dora/indicator.ts`(`nextTile`)・`doraSet.ts`(`resolveDora`)。

**受け入れ基準**
- Given リーチ+表ドラ2枚設定+赤5を1枚+北2枚抜き / When 和了(裏ドラ2枚該当なし) / Then ドラ由来の翻が正しく合算される
- Given 表ドラ表示牌が九萬 / When 次牌写像 / Then 実ドラは一萬(本変種固有)
- Given 表ドラ表示牌が9筒 / When 次牌写像 / Then 実ドラは1筒(巡回)
- Given 表ドラ表示牌が北 / When 次牌写像 / Then 実ドラは東(風牌巡回)
- 特性: オール赤5・ガリ・複数ドラめくりが重なり、満貫以上が頻発する

## 3.3 ソシー精算

**基本レート: 素点1点 = 1ソシー。**

精算 = ①素点(1点=1ソシー) + ②順位ウマ + ③祝儀 の合算。プレイヤーごとにソシーを累計する。

### ① 素点(オカ)
- 各プレイヤーの最終持ち点をそのままソシー換算(1点=1ソシー)。
- **オカ = 返し40,000 を基準**に配分。配給原点35,000×4人 − 返し40,000×4人 = **−20,000** を1位が受け取る(1位に +20,000 加点)。これによりウマ込みの精算総和はゼロになる。
- 集計対象は**4兄弟全員**(着席3人+抜け番1人)。持ち点は局をまたいで永続・抜け番中は不変(Q5・4.4)。

### ② 順位ウマ(千点単位)= 4人の最終順位に適用(Q13)

半荘終了時、**着席/抜け番を問わず4兄弟全員をその時点の持ち点で順位付け**し、4段ウマをそのまま割り当てる(3人に丸めない)。

| 順位 | ウマ |
|---|---|
| 1位 | **+10,000 ソシー**(表記「+10」) |
| 2位 | +5,000 ソシー(「+5」) |
| 3位 | -5,000 ソシー(「-5」) |
| 4位(最下位) | -10,000 ソシー(「-10」) |

- ウマ総和 = +10 +5 −5 −10 = **0**(千ソシー単位、総和ゼロ)。
- 千点=千ソシー(Q2)。同点順位の裁定は起家/席順の慣行に従う(実装で確定させてよい)。

### ③ 役満祝儀
- 役満和了時、**全員から1,000ソシー**。
- **先着1名のみ**(その半荘で最初の役満者)。
- **数え役満は対象外**。
- **パオ(責任払い)あり**: 大三元・大四喜・四槓子。パオ確定牌を打った者が責任払い。

**受け入れ基準**
- Given 大三元をパオ確定打牌で確定 / When ロン和了 / Then 放銃者/パオ者が責任払い、祝儀は全員から1,000ソシー
- Given 数え役満で13翻 / When 和了 / Then 点数は役満だが**祝儀は付かない**

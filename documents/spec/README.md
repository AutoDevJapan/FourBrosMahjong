## 用語(基本)

| 用語 | 意味 |
|---|---|
| サンマ | 三人打ち麻雀 |
| 四人回し | 4人中1人が抜け番になり交代で打つ運用 |
| ガリ | 北を抜きドラとして扱う抜き牌操作(北をツモったら晒して嶺上補充) |
| ソシー | 勝敗可視化のための動画内独自通貨。**素点1点 = 1ソシー** |
| オール赤5 | 5筒・5索がすべて赤ドラ(計8枚) |

## 完了基準(スペック全体)

- [ ] 108枚の牌構成でサンマの1局を配牌〜和了/流局まで進行できる
- [ ] 北抜き(ガリ)・ポン・カン・リーチ・ツモ/ロンが規定通り処理される
- [ ] ドラめくり(2個振り・1/2/3枚・裏ドラ同枚数)が各局で正しく適用される
- [ ] 点数が標準テーブル(符計算なし)で算出され、赤・ガリ・ドラが加算される
- [ ] 局ごとに抜け番が交代し、各プレイヤーの点棒が保持・再参加される
- [ ] 終了条件(オーラス親3万超えトップ / トビ)で半荘が終了する
- [ ] 素点・ウマ・祝儀を合算したソシー個人累計で最終順位が決まる

## 未確定(実装前に要回答)

確定回答から一意に定まらない設計論点は `質問リスト.md`(ルート)の「未回答 / 要確認」に集約し、解決状況・件数の管理も同ファイルに単一化する(この README には転記しない)。
**未確定の論点は存在する**(本文更新時点では Q22:役なし形式テンパイの扱い / Q23:天和・地和と配牌ガリの共存、が未回答)。該当領域を実装・変更する前に必ず `質問リスト.md` の最新状態を確認すること。
解決済み論点のスペック反映先の例: 「局ごと交代と東南戦(場・親ローテ)の相互作用」(Q9〜Q11)は**北家抜けの回転モデル**として確定(`game-flow.md` 2.5・2.6、`domain-model.md` 4.5)。ツモ配分(Q12)・ウマ割当(Q13)は `scoring-and-settlement.md` 3.1・3.3 に確定。

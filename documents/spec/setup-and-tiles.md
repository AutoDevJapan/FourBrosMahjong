# スペック1: 卓構成・四人回し・使用牌・配給原点

対象: 対局開始前のセットアップと、盤面の静的構成。出典背景は `docs/四兄弟麻雀ルール.md`。

## 1.1 卓構成と四人回し

- 基本は**三人打ち(サンマ)**。同時に打つのは常に **3人**。
- メンバーは **4人**。**局ごとに1人が抜け番**となり交代する(四人回し)。
- 各プレイヤーは**自分の点棒スタックを保持**する。抜け番中は点棒が変動せず固定。**復帰時は自分の点数で再参加**する。
- 最終順位・勝敗は**ソシー個人累計**で決定する(→ スペック3)。

**完了基準**
- [ ] 4人のプレイヤーを管理し、各局で3人が着席・1人が抜け番になる
- [ ] 抜け番中プレイヤーの点棒が変化しない
- [ ] 各プレイヤーの点棒が局をまたいで永続する

> ⚠️ 抜け番の順序、着席3人の席(東/南/西)割り当て、東南戦の「場」進行と親ローテの関係は**未確定**。`質問リスト.md` Q9〜Q11 を参照。確定まで着席・親決定ロジックは実装しない。

## 1.2 使用牌(計108枚)

サンマ標準の牌構成。**萬子は2〜8を抜く**。

| 種別 | 牌 | 枚数 |
|---|---|---|
| 萬子 | 一萬・九萬 | 各4枚 = 8枚 |
| 筒子 | 1〜9筒 | 各4枚 = 36枚 |
| 索子 | 1〜9索 | 各4枚 = 36枚 |
| 字牌 | 東・南・西・北・白・發・中 | 各4枚 = 28枚 |
| **合計** | | **108枚** |

### 赤ドラ(オール赤5)
- **5筒×4枚・5索×4枚の計8枚すべてが赤**(通常の黒5筒・黒5索は存在しない)。
- 萬子に5は無い(2〜8を抜くため)。
- 赤5は和了時に1枚1翻(ドラ)として加算。

### 北(ガリ=抜きドラ)
- 北4枚は局中に通常の字牌として存在するが、**抜きドラ**として扱う(操作は → スペック2 の北抜き)。

**完了基準**
- [ ] 山生成時に108枚が正しい種別・枚数で構成される
- [ ] 5筒・5索はすべて赤フラグを持つ
- [ ] 牌のモデルが「種別・数・赤フラグ」を表現できる(→ スペック4)

## 1.3 配給原点

- **配給原点: 35,000点持ち / 返し 40,000 相当**(関西サンマ標準)。
- 順位ウマ・オカの基準はこの返し点に準拠(具体額 → スペック3)。

**受け入れ基準(Given-When-Then)**
- Given 対局開始 / When 配牌前 / Then 着席3人の持ち点が各35,000点である
- Given 精算 / When 順位確定 / Then 返し40,000を基準にオカ・ウマを算出する

## 1.4 進行の基本制約(先付けナシナシ系)

| 項目 | ルール |
|---|---|
| チー | **不可**(サンマのためポン・カンのみ) |
| 喰いタン | **なし** |
| 後付け | **なし**(先付け/ナシナシ寄り) |
| 喰い替え | **なし** |

**完了基準**
- [ ] チー操作が存在しない
- [ ] 喰いタン・後付け・喰い替えが役判定/鳴き判定で禁止される
